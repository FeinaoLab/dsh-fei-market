# 🛒 飞市商城

> 飞市商城（主站）—— 一站式电商主站解决方案

## 📖 项目简介

飞市商城是一个功能完善的电商平台主站系统，支持多商户入驻、商品管理、订单处理等核心电商业务，为商家和消费者提供流畅的购物体验。

## ✨ 主要特性

- 🏪 **多商户入驻** —— 支持多商家独立入驻，统一管理
- 📦 **商品管理** —— 完整的商品上架、分类、库存管理
- 🛍️ **订单系统** —— 全流程订单处理，从下单到售后
- 💳 **支付集成** —— 支持多种主流支付方式
- 📊 **数据统计** —— 实时销售数据与运营分析
- 🔐 **安全可靠** —— 完善的权限控制与数据安全机制

## 🚀 快速开始

```bash
# 克隆仓库
git clone https://github.com/FeinaoLab/dsh-fei-market.git

# 进入项目目录
cd dsh-fei-market

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```
