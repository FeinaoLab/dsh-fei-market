## 五、踩坑记录

1. **npx 装 dsh 要 30 分钟**——不是 npm 慢，是依赖树里有 Electron，二进制下载走代理极慢。桌面端用户无此痛（官方安装器直发）。
2. 索引仓库初推时把插件目录当内嵌 git 仓库带进去了（gitlink），已 `git rm --cached` + `.gitignore` 修正——**插件和索引分仓**是正确姿势。
3. npm 版本发布走 `publishConfig.access: public`；git 源不需要 npm 发版，index 直接钉 commit，对我们这种非 npm 项目最省事。
